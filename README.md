## ✨ Features

- 🏠 Property listings
- 🔍 Property search and filters
- 💰 Property price information
- 🛏 Bedroom filtering
- ⚖️ Property comparison
- ❤️ Wishlist
- ⭐ Property ratings
- 💬 Customer reviews
- 🏡 Property details pages
- 👨‍💼 Agent pages
- 📱 Responsive design
- 📊 User dashboard
- 🔐 Login and registration pages
- 🖼️ Property gallery
- 📞 Contact section
- 📅 Property visit booking
- 💵 EMI calculator
